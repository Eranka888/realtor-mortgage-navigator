# Ипотечный навигатор риелтора

Веб-приложение для расчёта и сравнения ипотечных сценариев во время консультации. Риелтор может рассчитать вариант сделки, сохранить его, изменить условия и сравнить два или три сценария рядом.

«Ипотечный навигатор риелтора» — прикладное Streamlit-приложение для расчёта, сохранения и сравнения ипотечных сценариев. Проект разработан как самостоятельный MVP и подготовлен для публичной демонстрации в профессиональном портфолио. Расчёты предварительные: приложение не является банковским решением и не оценивает вероятность одобрения ипотеки.

**Публичная демонстрация:** [Открыть приложение](https://realtor-mortgage-navigator.streamlit.app)

## Возможности

- расчёт по стоимости недвижимости, первоначальному взносу, ставке и сроку;
- ввод первоначального взноса в процентах или рублях;
- аннуитетные и дифференцированные платежи;
- сумма кредита, первый и последний платежи, общая сумма выплат и переплата;
- подробный график платежей и интерактивные графики Plotly;
- экспорт графика платежей в CSV;
- сохранение, открытие и редактирование сценариев;
- сравнение двух или трёх сохранённых сценариев;
- светлая и тёмная темы.

## Режимы хранения сценариев

### Локальный режим

Используется по умолчанию. Сценарии хранятся в SQLite-файле `data/scenarios.db` на компьютере пользователя и остаются доступными после перезапуска приложения.

### Публичный demo-режим

Включается переменной окружения `PUBLIC_DEMO=true`. Общая SQLite-база в этом режиме не используется: для каждой Streamlit-сессии создаётся отдельное хранилище в памяти.

Сценарии одного посетителя не видны другим посетителям и могут исчезнуть после завершения сессии. В интерфейсе показывается предупреждение не вводить персональные данные.

Пример запуска demo-режима в PowerShell:

```powershell
$env:PUBLIC_DEMO="true"
python -m streamlit run app.py
```

После проверки переменную можно удалить:

```powershell
Remove-Item Env:PUBLIC_DEMO
```

## Локальный запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

После запуска Streamlit выведет локальный адрес, обычно `http://localhost:8501`.

## Как пользоваться

1. Укажите стоимость недвижимости, первоначальный взнос, ставку, срок и тип платежа.
2. Посмотрите показатели, график платежей и визуализации.
3. Введите название и сохраните первый сценарий.
4. Измените условия и сохраните следующий сценарий.
5. Выберите два или три варианта для сравнения.
6. При необходимости откройте сохранённый сценарий, измените его и сохраните обновление без создания дубля.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют ипотечные расчёты, SQLite-хранилище, session-only хранилище, сохранение и обновление сценариев, изоляцию demo-сессий, сравнение и интерфейсную логику.

## Ограничения MVP

- нет авторизации и многопользовательских аккаунтов;
- нет банковских интеграций и актуальных предложений банков;
- приложение не оценивает вероятность одобрения;
- нет API, CRM и общего постоянного облачного хранилища;
- в публичном demo-режиме данные временные и существуют только в текущей сессии.

Не вводите реальные персональные данные клиентов.

## Безопасность

Секреты, `.env`, `.streamlit/secrets.toml`, виртуальные окружения, кэши и локальные базы исключены из Git. Для работы приложения API-ключи и другие секреты не требуются.

## Если создание виртуального окружения не работает в Windows

Если команда `python -m venv .venv` завершается с `PermissionError` или `WinError 5`, связанными с `%LOCALAPPDATA%\Temp`, не меняйте системные разрешения и не запускайте PowerShell от имени администратора.

Создайте доступную временную папку и только для текущего окна PowerShell направьте в неё `TEMP` и `TMP`:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\venv-temp" | Out-Null
$env:TEMP="$env:USERPROFILE\venv-temp"
$env:TMP="$env:USERPROFILE\venv-temp"
python -m venv .venv
```

После закрытия окна PowerShell эти значения переменных окружения перестанут действовать.
